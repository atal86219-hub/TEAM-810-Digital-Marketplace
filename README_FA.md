# TEAM 810 Digital Marketplace

یک پروژه ساده برای بازار دیجیتال TEAM 810 شامل:
- صفحه خوش‌آمدگویی با حدیث و چهار زبان (دری، انگلیسی، پشتو، عربی)
- بخش پیش‌نمایش و سه قالب HTML آغازین قابل بازکردن
- ثبت خدمت فریلنسری با ذخیره در SQLite هنگام اجرای سرور
- ابزار ساخت و دانلود QR Code (برای بارگذاری کتابخانه QR به اینترنت نیاز دارد)
- جستجو و طراحی واکنش‌گرا برای موبایل

## اجرای محلی
نیاز به Python 3.10 یا بالاتر:
```bash
pip install -r requirements.txt
python app.py
```
سپس مرورگر را به `http://127.0.0.1:5000` باز کن.

## انتشار روی Render
1. محتویات این پوشه را در یک مخزن GitHub بارگذاری کن.
2. در Render یک **Web Service** از مخزن بساز.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `gunicorn app:app`
5. برای دیتابیس پایدار در Render، یک Persistent Disk بساز و متغیر `TEAM810_DB_PATH` را به مسیر داخل دیسک تنظیم کن، مثلاً `/var/data/team810.sqlite3`.
6. پس از استقرار، آدرس HTTPS سایت را باز کن.

## نکات مهم
- این نسخه یک پایه کاربردی است، نه یک بازار تجاری کامل.
- ثبت خدمت و ذخیره‌سازی SQLite با سرور فعال است؛ اگر فقط `index.html` را مستقیم باز کنی، API و ذخیره‌سازی سروری کار نمی‌کند.
- حساب کاربری، پنل مدیر، پرداخت آنلاین، کوتاه‌سازی واقعی لینک، آمار بازدید، درآمد تبلیغاتی و هشدار تلگرام هنوز پیاده‌سازی نشده‌اند.
- قبل از انتشار عمومی، ضداسپم، بررسی/مدیریت آگهی‌ها، حریم خصوصی و پشتیبان‌گیری دیتابیس را اضافه کن.
- هیچ API key لازم نیست؛ QR Code از یک کتابخانه CDN بارگذاری می‌شود و برای ساخت QR اینترنت لازم است.
